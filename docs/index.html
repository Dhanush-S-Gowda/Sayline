Spoken punctuation, decimal points, uppercase dictation, bullet lists, character backspace, and a command guide beside the punctuation button.

Format as you speak.

Enable Spoken punctuation in the dictation overlay to convert English voice commands into punctuation, symbols, numbers, and text formatting. Commands are case-insensitive. The option is off by default, and your preference is saved between sessions.

Creating bullet lists

Say start key point to begin a list, next point for each additional item, and stop key point to return to paragraph text. The next point command is active only in list mode. Joined and plural forms, such as start keypoints, are also supported.

Dictating command words

Prefix any command with literal to insert its words without executing it.

Say literal comma to insert the word comma rather than ,. Say literal start key point to insert start key point without starting a list.

To explore the commands, select Try the demo and enable its punctuation button. Hover over ? for two seconds, or select it, to open the command reference.

Uppercase and list modes apply to the current dictation session and reset when the session ends. Uppercase mode affects dictated text only; the keyboard’s Caps Lock setting is unchanged. Backspace removes one character from the current dictation.

Browser demo controls: Ctrl + Space opens or closes the demo while this page has focus. Esc closes the command guide first, then the demo. If another application reserves the shortcut, use the Try the demo button.
